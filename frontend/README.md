# Frontend

The frontend is a set of static HTML pages with shared styling and browser-side JavaScript. The pages cover the home page, students, registrations, and admin management.

Run the backend from `backend/` and open [http://localhost:3000](http://localhost:3000). The Express server serves these files and the API; opening the pages directly from disk will not provide a working API connection.

See the [project README](../README.md) for setup instructions and API details.
